# Nexora Website

A responsive React + Vite landing website for Nexora, the technology and digital innovation brand within the proposed Maurya Group brand architecture.

## Included
- Responsive navigation and mobile menu
- Dark hero and light content sections
- Nexora AI, Nexora Software, TechVerse and Nexora Games product cards
- Product detail modal with roadmap/status language
- Featured TechVerse concept preview
- Education & media section for Vikas Maurya Academy, Vikas Coding School and Vikas Gaming
- About section, contact form demo, and footer
- Responsive CSS, keyboard focus states, reduced-motion support

## Run locally

Requirements: Node.js 18+ (recommended)

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
npm run preview
```

## Before publishing
1. Replace the demo contact form handler with a secure backend or form service. The current form intentionally does not send or store data.
2. Add real contact details, social links, legal pages and privacy policy as appropriate.
3. Confirm which products are launched, in development, or planned, then update the status labels accurately.
4. Verify the Nexora and product names, domain availability, trademarks, and legal business structure.
5. Review accessibility and performance after adding production assets and integrations.

## Brand architecture shown
- Maurya Group — proposed parent group
- Maurya Education — Vikas Maurya Academy and Vikas Coding School
- Vikas Gaming — separate creator/gaming brand
- Nexora — technology and digital innovation brand
  - Nexora AI
  - Nexora Software
  - TechVerse (learning platform in development)
  - Nexora Games (future venture)

This is a front-end starter project. It does not claim that planned products are already launched or that the contact form is connected to a service.
